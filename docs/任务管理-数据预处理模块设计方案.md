# 任务管理 — 数据预处理模块设计方案

## 1. 需求概述

用户在任务管理模块创建任务前，需要先上传 Excel 文件提取关键词，拿到关键词后用于创建素材抓取任务。

**流程简化：** 不复用任务执行器体系，而是前端直接调用已有的文件处理接口完成关键词提取，再创建任务。

```
用户上传 Excel → POST /api/file/process (handlerType=excel) → 返回关键词列表
                                                                    ↓
                                             用户确认后创建素材抓取任务 → POST /api/task/create
```

## 2. 现有可复用接口

**`POST /api/file/process`**（`FileController#processFile`）

- 入参：`file`（MultipartFile）+ `handlerType`（String）
- 响应：`BaseResponse<Object>`
  ```json
  {
    "code": 0,
    "msg": "success",
    "data": {
      "searchKeywords": ["阿坝九寨沟沟口集市氛围感空镜", "阿坝漳扎镇氛围感空镜"]
    }
  }
  ```
- handlerType 映射通过 QConfig `task_common_config.properties` 配置：
  ```properties
  file.processor.handler.types=excel:excelFileProcessor
  ```

`ExcelFileProcessor` 读取 Excel 第一列（跳过表头），直接通过 EasyExcel 流式读取，不上传 OSS、不持久化。

## 4. 涉及改动

### 4.1 已完成的改动

| 文件 | 改动 | 状态 |
|------|------|------|
| `web/FileController.java` | 返回类型 `BaseResponse<Map<String, List<String>>>` → `BaseResponse<Object>` | ✅ 已改 |
| `service/file/ExcelFileProcessor.java` | Excel 第一列提取（跳过表头） | ✅ 已建 |
| `service/file/FileProcessor.java` | 处理器接口 | ✅ 已建 |
| `infra/qconfig/TaskCommonConfig.java` | 新增 `getString()` | ✅ 已改 |

### 4.2 无需额外改动

- 不需要 `DataPreprocessExecutor`
- 不需要新增任务类型
- 不需要新增文件上传到 OSS 的接口
