## 关键设计要点

### 数据模型
- **tag_category**：多级树形分类，path 字段支持子树快速查询
- **tag_leaf**：叶子标签，必须关联 is_leaf=1 的末级分类

### 业务规则
- 末级分类才能关联叶子标签
- 停用分类递归停用子分类和子标签
- 删除前检查关联数据

### 极端场景
- 末级分类 ↔ 非末级分类互转：需检查关联数据
- 标签转分类：停用原标签 + 创建新分类结构
- 批量打标：批量插入 + 异步日志
