# 任务模块架构设计

## 一、执行器与数据源分离架构

### 1.1 核心概念

```
┌─────────────────────────────────────────────────────────────┐
│                        Task (主任务)                         │
│  定义：任务的总体配置和调度                                   │
│                                                              │
│  task_params = {                                             │
│    "dataSource": {...},    // 数据源配置                     │
│    "executor": {...}       // 执行器配置                     │
│  }                                                           │
└─────────────────────────────────────────────────────────────┘
                              │
           ┌──────────────────┴──────────────────┐
           ▼                                      ▼
┌─────────────────────────┐      ┌─────────────────────────┐
│     DataSource          │      │       Executor          │
│     (数据源配置)          │      │     (执行器配置)         │
│                         │      │                         │
│  定义：数据从哪来          │      │  定义：怎么处理数据       │
│  - 数据类型               │      │  - 执行逻辑              │
│  - 筛选条件               │      │  - 参数配置              │
│  - 数量限制               │      │  - 超时重试              │
└─────────────────────────┘      └─────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    SubTask (子任务)                          │
│  定义：每条数据对应一个子任务                                  │
│                                                              │
│  business_key: 具体数据ID（如 material_id）                   │
│  executor: 子任务执行器（如 TaggingChildExecutor）            │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 数据源类型 (DataSourceType)

```java
public enum DataSourceType {
    /**
     * 指定ID列表 - 手动输入素材ID
     */
    ID_LIST("ID_LIST", "指定ID列表"),

    /**
     * Demo数据 - 用于测试验证
     */
    DEMO_DATA("DEMO_DATA", "Demo数据");
}
```

### 1.3 执行器类型 (ExecutorType)

```java
public enum ExecutorType {
    /**
     * AI打标执行器
     * 流程：抽帧 → 识图 → ASR → 合并结果
     */
    AI_TAGGING("AI_TAGGING", "TaggingParentExecutor", "AI打标"),

    /**
     * 数据统计执行器
     */
    DATA_STATISTICS("DATA_STATISTICS", "StatisticsExecutor", "数据统计"),

    /**
     * 报告汇总执行器
     */
    REPORT_SUMMARY("REPORT_SUMMARY", "SummaryExecutor", "报告汇总");
}
```

### 1.4 task_params JSON Schema

```json
{
  "dataSource": {
    "type": "RAW_CONTENT",
    "filter": {
      "status": "pending",
      "createTimeStart": "2026-05-01",
      "createTimeEnd": "2026-05-10"
    },
    "limit": 100,
    "orderBy": "id ASC"
  },
  "executor": {
    "frameInterval": 5,
    "maxFrames": 10,
    "model": "gpt-4o",
    "enableAsr": true,
    "tags": ["flight", "hotel"]
  }
}
```

## 二、AI 打标执行器详细流程

### 2.1 主任务执行器 (TaggingParentExecutor)

```
Task 创建
    │
    ▼
┌─────────────────────────────────────┐
│ 1. 解析 dataSource 配置              │
│    - 查询符合条件的数据               │
│    - 生成 SubTask 列表               │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 2. 更新主任务状态为 RUNNING           │
│    - 更新 sub_task_count             │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 3. 分发子任务到执行队列               │
│    - QSchedule 定时拉取执行           │
│    - 或立即执行                       │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│ 4. 等待所有子任务完成                 │
│    - 汇总结果                         │
│    - 更新主任务状态                   │
└─────────────────────────────────────┘
```

### 2.2 子任务执行器 (TaggingChildExecutor)

```
SubTask (business_key = material_id)
    │
    ▼
┌─────────────────────────────────────┐
│ 1. 获取素材信息                       │
│    - 视频 URL                         │
│    - 已有关联标签                     │
└─────────────────────────────────────┘
    │
    ├──────────────────┬──────────────────┐
    ▼                  ▼                  ▼
┌──────────┐    ┌──────────┐    ┌──────────┐
│ 视频抽帧  │    │ 音频提取  │    │ 获取已有 │
│          │    │          │    │ 标签信息  │
│ Frame1   │    │ MP3      │    │          │
│ Frame2   │    │          │    │          │
│ ...      │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘
    │                  │
    ▼                  ▼
┌──────────┐    ┌──────────┐
│ 上传OSS  │    │ 上传OSS  │
│ 图片URL  │    │ 音频URL  │
└──────────┘    └──────────┘
    │                  │
    ▼                  ▼
┌──────────┐    ┌──────────┐
│ 大模型   │    │  ASR    │
│ 识图     │    │ 转写    │
│          │    │         │
│ 图像标签  │    │ 文本内容 │
└──────────┘    └──────────┘
    │                  │
    └────────┬─────────┘
             ▼
    ┌─────────────────────┐
    │ 合并分析             │
    │ - 图像标签           │
    │ - 音频文本           │
    │ - 已有标签           │
    │ - 提示词模板         │
    └─────────────────────┘
             │
             ▼
    ┌─────────────────────┐
    │ 最终标签结果         │
    │ - tags: [...]       │
    │ - confidence: 0.85  │
    │ - details: {...}    │
    └─────────────────────┘
             │
             ▼
    ┌─────────────────────┐
    │ 写入结果             │
    │ - 更新素材标签       │
    │ - 记录打标日志       │
    │ - 更新子任务状态     │
    └─────────────────────┘
```

## 三、状态机设计

### 3.1 主任务状态流转

```
                    ┌──────────┐
                    │ PENDING  │ (待执行)
                    └────┬─────┘
                         │ 开始执行
                         ▼
                    ┌──────────┐
         ┌──────────│ RUNNING  │──────────┐
         │          └────┬─────┘          │
         │               │                │
    手动取消         全部成功          全部失败/超时
         │               │                │
         ▼               ▼                ▼
    ┌──────────┐   ┌──────────┐   ┌──────────┐
    │CANCELLED │   │ SUCCESS  │   │  FAILED  │
    └──────────┘   └──────────┘   └──────────┘
```

### 3.2 子任务状态流转

```
    PENDING ──▶ RUNNING ──▶ SUCCESS
        │           │
        │           ├──▶ FAILED ──▶ (重试) ──▶ RUNNING
        │           │
        └───────────┴──▶ SKIPPED (跳过)
```

## 四、接口设计

### 4.1 任务管理接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/task/create` | POST | 创建任务 |
| `/api/task/list` | GET | 任务列表 |
| `/api/task/detail/{id}` | GET | 任务详情 |
| `/api/task/cancel/{id}` | POST | 取消任务 |
| `/api/task/retry/{id}` | POST | 重试任务 |
| `/api/task/delete/{id}` | DELETE | 删除任务 |

### 4.2 子任务接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/subtask/list` | GET | 子任务列表（按父任务ID） |
| `/api/subtask/detail/{id}` | GET | 子任务详情 |
| `/api/subtask/retry/{id}` | POST | 重试子任务 |

### 4.3 创建任务请求示例

```json
POST /api/task/create
{
  "taskName": "AI打标-原始内容-2026-05-11",
  "taskType": "AI_TAGGING",
  "executeTime": "2026-05-11 10:00:00",
  "taskParams": {
    "dataSource": {
      "type": "RAW_CONTENT",
      "filter": {
        "status": "pending"
      },
      "limit": 50
    },
    "executor": {
      "frameInterval": 5,
      "maxFrames": 10,
      "model": "gpt-4o",
      "enableAsr": true
    }
  }
}
```

## 五、前端页面设计

### 5.1 页面清单

| 页面 | 路由 | 说明 |
|------|------|------|
| 任务列表 | `/task/list` | 任务查询、筛选、操作 |
| 新建任务 | `/task/create` | 任务创建向导 |
| 任务详情 | `/task/detail/:id` | 任务进度、子任务、结果 |

### 5.2 交互流程

```
任务列表 ──▶ 新建任务 ──▶ 任务详情
    │                          │
    │                          ▼
    └──────────────────── 取消/重试/删除
```
