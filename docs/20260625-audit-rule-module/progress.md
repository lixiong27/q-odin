## 关键约定

### 接口规范
- 统一前缀：`/api`
- 统一响应格式：`{ code: 0, message: "success", data: {} }`

### QConfig 键名
- 字典配置：`audit_dict.json`

### 数据库
- 表名：`audit_rule`
- 业务唯一键：`rule_name`

### 前端路由
- 列表页：`/audit/rule/list`
- 新建页：`/audit/rule/create`
- 编辑页：`/audit/rule/edit/:id`
